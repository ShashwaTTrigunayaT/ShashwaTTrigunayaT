## Featured Project

### ◆ AetherStudio — Production-Grade Collaborative IDE

A real-time collaborative coding environment with:

| Capability | Tech | Detail |
|-----------|------|--------|
| **Real-time Sync** | Yjs CRDT + Socket.IO | Conflict-free, sub-50ms latency |
| **Code Execution** | Docker Sandbox | 512MB RAM, 0.5 CPU, no-network |
| **AI Assistance** | Google Gemini Pro | Code completion, analysis, chat |
| **Video Calls** | WebRTC Signaling | P2P audio/video collaboration |
| **Horizontal Scale** | Redis Pub/Sub | Multi-node without sticky sessions |
| **Languages** | 8+ Docker Images | Node, Python, C++, Java, Go, etc. |
| **Editor** | Monaco Editor | Full VS Code experience in browser |

**Architecture:** Solved Socket Scaling using Redis Pub/Sub to synchronize Yjs CRDT state across multiple server nodes. Implemented a Dockerized Sandbox with resource limits and network isolation for secure code execution.
